# AgenticLens

What did the agent do, and where did time, tokens, or cost go?

## What it does

Run artifacts, analysis, comparisons, and evidence-backed recommendations.

## What you need

Instrumented workflows, structured traces, or supported imported trace data.

## Start here

Record a small local trace and inspect run.json.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

Recommendations are advisory. Its richer dataset and experiment workflows do not make every third-party trace schema automatically compatible.

[Read the detailed developer guide](developer-guide.md).
